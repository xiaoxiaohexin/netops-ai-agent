# 智能网络运维Agent前端设计与架构文档

## 1. 概述 (Overview)
本项目为一个基于大语言模型（LLM）驱动的**智能网络运维Agent**纯前端应用。界面设计参考了经典的工业级网络仿真软件**思科 Packet Tracer (PT)**，强调实用性、画布为核心的空间布局以及高密度的信息展示。该系统旨在通过自然语言交互，辅助网络工程师完成拓扑可视化、故障自动诊断、性能排查、自动修复、配置下发与回滚等任务。

## 2. 技术栈选型 (Tech Stack)
本项目采用现代前端主流技术栈，确保在保证开发效率的同时，达到企业级工业标准的设计和交互体验。

* **核心框架**: React 19 (TypeScript) - 提供组件化与强类型的应用基础。
* **UI 组件库**: Ant Design (antd) - 工业级中后台设计体系。用于构建标准的导航布局、抽屉（Drawer）、模态框（Modal）、表格（Table）以及表单（Form）。
* **拓扑图渲染**: React Flow (`@xyflow/react`) - 用于构建可交互的、基于节点（Node）和连线（Edge）的网络拓扑图。
* **样式引擎**: Tailwind CSS - 负责全局布局辅助、细粒度的间距微调和响应式设计。
* **图标系统**: `@ant-design/icons` & `lucide-react` - 提供专业的网络与UI系统图标。

## 3. 界面布局设计 (UI Layout)
整体界面采用“上-中-左右-下”的经典工业软件布局（Cisco PT 风格变体）：

1. **顶栏 (Header Toolbar)**
   - 全局控制中心：提供“导入知识库”、“生成诊断报告”、“导出审计日志”等全局操作入口。
2. **左侧边栏 (Toolbox/Assets)**
   - 资产库/工具箱：提供不同类型的网络设备（路由器、交换机、服务器）视图（本版本作为静态展示/过滤器）。
3. **中央主画布 (Topology Canvas)**
   - 核心工作区：使用 React Flow 渲染网络拓扑。支持拖拽缩放。节点颜色反映设备健康状态（绿=正常，黄=警告，红=故障）。
4. **右侧面板 (Agent Chat & Properties)**
   - **上半部分 (属性与诊断)**：当在画布中点击设备节点时，弹出或显示该设备的详细信息（CPU/内存负载、端口状态、异常处理建议）。
   - **下半部分 (Agent 交互端)**：AI 自然语言对话框。支持输入指令（如：“排查 Switch-01 为什么断连并尝试重置端口”）。
5. **底栏 (Audit Logs / Terminal)**
   - 终端/日志视窗：滚动显示自动生成的审计日志、操作历史、回滚记录，营造专业运维氛围。

## 4. 组件交互与业务逻辑设计

### 4.1 网络拓扑与设备诊断 (React Flow 交互)
* **节点(Node)**: 自定义 React Flow 节点，集成设备图标、名称和状态指示灯。
* **点击事件(onClick)**: 点击节点将触发状态更新，打开 Ant Design 的 `Drawer` 组件，展示该设备的多维度详情。
* **详情面板**: 包含多个 Tabs 标签页：
  1. **性能指标**: 展示吞吐量、延迟、丢包率等。
  2. **故障诊断**: 如果状态异常，显示 AI 生成的自动诊断原因及修复建议。
  3. **配置记录**: 模拟设备本地历史配置版本，支持点击“回滚”。

### 4.2 Agent 自然语言运维对话
* **指令解析模拟**: 用户在右侧聊天框输入指令（如“重连 Router-A”），系统解析指令并更新本地状态变量。
* **状态联动**: 聊天操作完成后，拓扑图中对应节点的连线或状态指示灯将从红色变为绿色，模拟问题修复。
* **审计追踪**: Agent 的每一个动作（诊断、下发配置、回滚）都会作为一条标准的系统日志推送到下方的“审计日志”面板中。

### 4.3 报告生成与知识库导入
* **知识库导入**: 触发 Ant Design 的 `Upload` 组件，模拟解析本地文本或PDF进入Agent上下文。
* **诊断报告**: 汇总当前拓扑的所有警告与故障信息，通过 `Modal` 展示可视化的 Markdown/图表排版报告，并支持模拟下载（导出）。

## 5. 按钮与库的精确映射关系

| 功能 / 按钮名称 | 交互动作 | 关联开源库 / 组件 |
| --- | --- | --- |
| **画布区域与连线** | 拖拽、缩放、图元渲染 | `@xyflow/react` (`ReactFlow`, `Background`, `Controls`) |
| **点击设备节点** | 打开右侧抽屉面板 | `antd` (`Drawer`, `Tabs`, `Descriptions`) |
| **导入知识库** | 弹出文件选择与进度提示 | `antd` (`Upload`, `message`) |
| **生成诊断报告** | 弹出全局汇总报告窗口 | `antd` (`Modal`, `Table`, `Timeline`) |
| **Agent Chat 提交** | 发送对话，触发UI状态更新 | `antd` (`Input`, `Button`, `List`) |
| **执行回滚 / 变更** | 二次确认后触发配置变更日志 | `antd` (`Popconfirm`, `notification`) |
| **底部日志滚动区** | 记录并展示所有自动化运维流 | `antd` (`Table` / HTML `div` with custom styles) |
